A native block theme for Atlas Relics.

== Description ==

Atlas Relics is an editorial block theme for a house of tools, reflections, and artifacts. It uses theme.json design tokens, WooCommerce block templates, and no page builder.

Business logic belongs in the Atlas Relics Core plugin.
